# Projeto Banco de Dados - SQL (SQLite)

Projeto desenvolvido para a disciplina de Banco de Dados.

// Estrutura do Repositório:
- `schema.sql`: Contém a DDL (criação de tabelas) e DML (inserção de dados de teste).
- `queries.sql`: Contém as consultas SQL referentes às perguntas do projeto.

// Como Executar no SQL Fiddle / SQLite Online:
1. Acesse o [SQLite Online](https://sqliteonline.com/) ou [SQL Fiddle](https://sqlfiddle.com/).
2. Selecione o SGBD **SQLite**.
3. Copie e execute o conteúdo de `schema.sql` para criar e povoar as tabelas.
4. Execute as consultas do ficheiro `queries.sql` para visualizar os resultados.
